# Pouches Mod
## What is it?
Adds a new plant in Minecraft and new recipes for pouches.  
These pouches, while at the beginning may give the player positive effects, it's only a matter of time before they hit back.  

## Modding APIs / Frameworks
Java 21.0.5 (OpenJDK, Temurin)  
Fabric / Fabric API (Mojang mappings)  
Gradle  
Minecraft 1.21.1
